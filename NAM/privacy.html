Privacy

Privacy policy

What this website collects—and what it does not.

Website visitors

This website has no accounts, cookies, advertising, user IDs, fingerprinting, behavioral profiling or cross-site tracking. The optional feedback form sends information only when you choose Send feedback. Cloudflare Web Analytics separately receives a cookie-free page-view beacon for aggregate traffic and performance statistics; browser-only warehouse profiles and inventory are never included. When enabled, Cloudflare Web Analytics receives a page-view beacon on each page load with page, referrer, country, device, browser, operating-system and performance data for aggregate statistics. Cloudflare states that the service uses no cookies or localStorage and does not fingerprint or track individuals across sites. This site disables SPA route-change tracking, sends no custom events, and does not pass browser-only warehouse profiles or inventory to the beacon.

Feedback and contact messages

The form collects the message category, subject, message, required reply email, optional Discord username, and limited debugging context: page paths, project version, language, theme, browser family and major version, operating-system family, and viewport size. It does not read warehouse, route, crafting, inventory, or other browser-stored data. The information is used only to understand the submission, improve the project, and contact you when needed.

Formspree and the network services involved may process the IP address and request metadata technically needed to receive, protect, and deliver a submission.

How long is it kept?

Formspree delivers submissions and stores its copy for up to 30 days. A copy in the separate project mailbox is deleted when the matter is resolved and always within 12 months. It is not used for newsletters, marketing, supporter lists, or game advantages.

Market information we publish

We publish Naval Action item names, ports, current shop prices and stock, source timing, and the following bounded historical aggregates: availability frequency; 7-, 30-, and 90-day medians and differences; event flags; and context scores with their components. The route tools also calculate clearly labelled scenario profit estimates from public planning inputs. Player contracts and the complete private source files are not published. The historical-intelligence data contains no profit calculations or predictions.

The owner’s private Google access

The private updater uses Google Drive only for its named private evidence folder and checkpoints. The private Google Sheet is manual-only and is not part of the daily public workflow. Visitors never sign in with Google, and the site does not read, sell, or share their Google account data.

Storage and control

The owner keeps private market files and saved reports to compare prices over time. The owner can remove Google access at any time and delete those private files. The public site holds no visitor profile to delete.

Your local warehouse profiles

If you use the warehouse page, its named profiles and inventory are stored only in your browser. The public site receives no copy, identifier, fingerprint, or synchronization record.

Shared warehouse links

A shared warehouse link contains one encrypted snapshot of one or all warehouses in the selected profile plus its opening key. The profile name and history are excluded. The browser creates and reads the link; this site does not upload or store the snapshot, and analytics is disabled on the Shared warehouses page. Anyone with the complete link can open and forward it. A sender label is optional and unverified. Nothing is retained until the recipient explicitly chooses Save in Shared with me or Save and download Excel; downloaded workbooks are created locally in that browser.

Hosting

GitHub Pages hosts this website and may process basic technical details needed to load it under GitHub’s privacy statement. When analytics is enabled, Cloudflare receives the beacon data described above and gives the site owner aggregate traffic and performance statistics. GitHub privacy statement. Cloudflare Web Analytics.

Contact and changes

Use the feedback form and choose “Privacy or security concern” to ask about, correct, or delete a submission. Important policy changes will be published on this page. Feedback & contact.

Optional developer IP check

Only after activation in a browser, this website asks ipify for its public IPv4 address to show a developer link. It checks when opening or returning to a page and every five minutes while the page is visible. Ipify receives the IP address and technical request metadata, but no routes, inventory, screenshots, voyage records or referring page. No cookies are sent. Only the on/off choice is stored locally, never the IP address. Disable it on the developer page. The standalone trip-log and shared-warehouse pages never perform this check. The daily collector checks the public logging claim and availability; this cannot prove internal server logging. The feature hides a menu link and is not access control.
