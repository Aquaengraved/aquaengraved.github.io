v0.4.6Configuration comparison and Congreve OCR hotfix

Shows raw modifier-ledger differences in configuration comparisons and recognizes the recurring OCR text ‘rapd Congreve’ as 12pd Congreve when the catalogue provides one unique match.

Date
31-08-2026
Views
Not available

What changed

  • Configuration comparison now includes raw API modifier totals from selected woods, permanent upgrades and knowledge. Missing source ledgers remain Not comparable instead of being treated as zero.
  • Warehouse screenshot import now recognizes the recurring ‘rapd Congreve’ OCR result as ‘12pd Congreve’ only when the catalogue contains one unique match. Ambiguous and incomplete names remain excluded for review.

Displayed views are accepted only from an aggregate snapshot that excludes known bots. The totals do not identify people, use cookies, or represent unique visitors.
