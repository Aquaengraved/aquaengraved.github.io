Freiwillige Unterstützung

Entwicklung unterstützen

Naval Action Automation ist ein unabhängiges Community-Projekt und bleibt für alle kostenlos nutzbar.

Wenn Sie die Werkzeuge nützlich finden, können Sie freiwillig ein einmaliges Trinkgeld für ihre weitere Entwicklung und Wartung geben.

Trinkgelder schalten keine Funktionen frei, erkaufen keine Priorität und verschaffen keinen Vorteil im Spiel. Wiederkehrende Unterstützung ist auf Ko-fi für Personen verfügbar, die sich ausdrücklich dafür entscheiden, ist aber niemals erforderlich.

Naval Action Automation ist weder mit Naval Action noch mit dessen Entwicklern verbunden und wird von ihnen weder gebilligt noch gesponsert.

Trinkgeld über Ko-fi geben ↗

Ko-fi wird in einem neuen Tab geöffnet. Die Zahlung wird extern von Ko-fi und PayPal abgewickelt. Auf dieser Website werden keine Zahlungsdaten eingegeben oder verarbeitet.

Naval Action Automation ist ein unabhängiges Spielerwerkzeug für Naval Action und weder mit Bermuda Computer Club verbunden noch von diesem unterstützt.
