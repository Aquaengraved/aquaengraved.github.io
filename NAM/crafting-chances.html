Source parameters and assumptions

The normal and improved tables are taken from the ship selected above. Missing parameters stay unavailable.

The selected baseline treats the improved 30% and 5% parameters as mutually exclusive quality outcomes: blue = 100% − 30% − 5%. This selection rule is a modelling assumption; the API does not publish the server's roll order. All ports with the same table use the same baseline.

Colour labels follow the player's slot-based interpretation. The client also considers built-in trim when displaying rarity, so the logger records colour, slots and trim separately. Trim uses the third module parameter: 40% normal and 70% improved. Crafting observations can refine these estimates.

Sources: publisher Ports export and publisher ItemTemplates export. The catalog snapshot is dated 2026-09-05; a live source may be newer.
