Community travel measurement

Record one port-to-port trip

Fill in one uninterrupted trip. Your browser creates a small file for you to send to the project owner.

Private by design: nothing you enter is uploaded, stored by this website, or sent to analytics. No name, account, email, or player identity is requested.

Trip details

Required fields are marked. One consistent timing rule keeps everyone’s logs comparable.

Timing rule: Start when Open World is visible and your ship can move. Stop when the destination’s Enter Port action becomes available. Use UTC.

Use the speed shown for this ship setup. This lets us compare different builds of the same ship.

Every honest log is useful. Direct solo trips form the baseline; other trips are retained separately so delays or fleets do not distort it.

For analysis: Empty is modelled at 85% speed; up to 65% filled at 100%; and more than 65% filled as a range from 85% to 100%.

After downloading

Send the file

  1. Find the downloaded file beginning with naval-action-trip-.
  2. Send that file to the project owner through your usual channel.
  3. The file can be analyzed directly. No screenshot is needed.

One file should describe exactly one port-to-port leg. Please start a new form for the next leg.

Estimates will only be labelled reliable after held-out trip logs show that at least 80% land within ±20% of the estimate. The form does not claim that accuracy before it has been measured.
