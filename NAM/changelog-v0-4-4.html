v0.4.4Private shared warehouses

Adds a separate Shared Warehouse page for sending one protected warehouse snapshot and keeping trusted snapshots in an expandable browser-local overview without accounts or server storage.

Date
30-08-2026
Views
Not available

What changed

  • The sender chooses one saved warehouse and may type an optional label. The label is shown as unverified because the site has no accounts or identity system.
  • The complete link is the permission. Its encrypted snapshot is created and opened in the browser, is not uploaded by this site, can be forwarded by anyone who has it, and has no live synchronization or revocation.
  • A recipient first sees a read-only preview. Only an explicit Keep in Shared with me action retains it in this browser. Every retained warehouse remains separate and can be expanded or collapsed independently.
  • Copying a received snapshot into personal Warehouse Manager data and removing a retained snapshot are separate explicit local actions. Missing, malformed, duplicate, or oversized data is rejected instead of becoming zero or partial inventory.
  • Recent warehouse changes now use a responsive column layout for profile, date, port, item, old value, new value, and signed change. Valid current profile names replace generic slot labels, while invalid or missing profile metadata falls back safely.
  • Dense four-column cannon screenshots receive narrow, evidence-backed recognition retries for clipped gun names and quantities. A lower-confidence quantity is accepted only when two distinct OCR crops produce the same positive value; missing, zero, conflicting, or insufficiently supported quantities remain unresolved for review.

Displayed views are accepted only from an aggregate snapshot that excludes known bots. The totals do not identify people, use cookies, or represent unique visitors.
