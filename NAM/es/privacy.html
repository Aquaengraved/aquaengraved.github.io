Privacidad

Política de privacidad

Lo que este sitio recopila y lo que no.

Visitantes del sitio

Este sitio no utiliza cuentas, cookies, publicidad, identificadores de usuario, huellas digitales, perfiles de comportamiento ni seguimiento entre sitios. El formulario opcional solo envía información cuando usted elige Enviar comentario. Cloudflare Web Analytics recibe por separado una baliza sin cookies para estadísticas agregadas de tráfico y rendimiento; nunca incluye perfiles de almacén ni inventarios del navegador. Cuando está activado, Cloudflare Web Analytics recibe con cada carga de página una baliza con datos de la página, el referente, el país, el dispositivo, el navegador, el sistema operativo y el rendimiento para generar estadísticas agregadas. Cloudflare declara que el servicio no usa cookies ni localStorage, no crea huellas digitales de las personas ni las sigue entre sitios. Este sitio desactiva el seguimiento de cambios de ruta en aplicaciones de página única, no envía eventos personalizados y no transmite a la baliza perfiles de almacenes ni inventarios guardados únicamente en el navegador.

Tu preferencia para contar las páginas vistas

Excluye este navegador del recuento de páginas vistas, por ejemplo mientras pruebas NAM. Solo se guarda una preferencia de activado/desactivado en este dispositivo; no se crea ningún identificador de visitante ni se comprueba ninguna dirección IP. La página se recarga cuando cambias el ajuste. Configúralo por separado en cada navegador. Las páginas vistas anteriormente no se pueden eliminar del recuento. Las vistas previas locales siempre quedan excluidas.

Mensajes de comentarios y contacto

El formulario recoge la categoría, el título, el mensaje, el correo obligatorio para responder, el nombre opcional de Discord y un contexto técnico limitado para la depuración: rutas de página, versión del proyecto, idioma, tema, familia y versión principal del navegador, familia del sistema operativo y tamaño de la ventana. No lee datos de almacenes, rutas, fabricación, inventario ni otros datos guardados en el navegador. La información solo se usa para comprender el envío, mejorar el proyecto y contactar con usted cuando sea necesario.

Formspree y los servicios de red implicados pueden tratar la dirección IP y los metadatos técnicos de la solicitud necesarios para recibir, proteger y entregar un mensaje.

¿Cuánto tiempo se conserva?

Formspree entrega los envíos y conserva su copia durante un máximo de 30 días. La copia del buzón separado del proyecto se elimina al resolverse el asunto y siempre dentro de 12 meses. Los datos no se utilizan para boletines, publicidad, listas de personas que apoyan el proyecto ni ventajas en el juego.

Información de mercado que publicamos

Publicamos nombres de objetos de Naval Action, puertos, precios y existencias actuales de las tiendas, marcas de tiempo de las fuentes y los siguientes agregados históricos acotados: frecuencia de disponibilidad, medianas y diferencias de 7, 30 y 90 días, indicadores de eventos y puntuaciones de contexto con sus componentes. Las herramientas de rutas también calculan estimaciones de beneficio claramente etiquetadas para distintos escenarios a partir de datos públicos de planificación. No se publican contratos de jugadores ni los archivos fuente privados completos. Los datos de inteligencia histórica de mercado no contienen cálculos de beneficios ni predicciones.

Acceso privado a Google del propietario

El actualizador privado usa Google Drive únicamente para su carpeta privada de pruebas designada y sus puntos de control. La hoja privada de Google Sheets es solo para uso manual y no forma parte del flujo público diario. Los visitantes nunca inician sesión con Google y el sitio no lee, vende ni comparte los datos de sus cuentas de Google.

Almacenamiento y control

El propietario conserva archivos privados del mercado e informes guardados para comparar precios a lo largo del tiempo. Puede retirar el acceso a Google en cualquier momento y eliminar esos archivos privados. El sitio público no conserva ningún perfil de visitante que se pueda eliminar.

Sus perfiles de almacenes locales

Si usa la página de almacenes, sus perfiles con nombre y el inventario se guardan únicamente en su navegador. El sitio público no recibe ninguna copia, identificador, huella ni registro de sincronización.

Enlaces de almacenes compartidos

Un enlace de almacén compartido contiene una instantánea cifrada de uno o todos los almacenes del perfil seleccionado, además de la clave para abrirla. El nombre del perfil y el historial quedan excluidos. El navegador crea y lee el enlace; este sitio no carga ni almacena la instantánea, y las analíticas están desactivadas en la página Almacenes compartidos. Cualquier persona que tenga el enlace completo puede abrirlo y reenviarlo. La etiqueta del remitente es opcional y no está verificada. No se guarda nada hasta que el destinatario elige expresamente Guardar en Compartidos conmigo o Guardar y descargar Excel; los libros descargados se crean localmente en ese navegador.

Alojamiento

GitHub Pages aloja este sitio y puede tratar los datos técnicos básicos necesarios para cargarlo conforme a la declaración de privacidad de GitHub. Cuando las analíticas están activadas, Cloudflare recibe los datos de la baliza descritos anteriormente y proporciona al propietario estadísticas agregadas de tráfico y rendimiento. Declaración de privacidad de GitHub. Cloudflare Web Analytics.

Contacto y cambios

Utilice el formulario y elija «Problema de privacidad o seguridad» para solicitar acceso, corrección o eliminación de un envío. Los cambios importantes de la política se publicarán en esta página. Comentarios y contacto.

Optional access to the Developer Update Desk

Only after one-time activation in this browser, the site asks the protected gateway for the developer link. Cloudflare necessarily receives the public IP address and ordinary technical connection metadata. Our Worker compares that address transiently with the private whitelist, does not store or log it, and sets no cookies. Only the on/off choice is stored locally in this browser. Every page file is checked again; an old or shared address returns an ordinary 404.
